# Pizza v0.5.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Switch the Copper Sword button from the `player-elevated` workaround to plain `run-as: console`, now that Copper Kingdom v0.3.0 supports console give-to-player.

**Architecture:** Config-only. One button edited in `config.yml`, one `ShippedConfigTest` string updated, the config hash appended, the version bumped. No Java source changes.

**Tech Stack:** Paper plugin, Java 25, Maven, SnakeYAML, JUnit 5.

## Global Constraints

- `command-allowlist` already contains `copperkingdom`; no allowlist change.
- Editing `config.yml` changes its SHA-256 — append the new hash as the last line of `config-hashes.txt`, keeping all existing lines. `ConfigHashesTest.currentDefaultHashIsListed` guards it.
- Config auto-refresh stays non-destructive: never remove/reorder existing hash lines.
- Version: `pom.xml` project version becomes `0.5.1`.
- Must land in ONE task: editing `config.yml` invalidates the current-default hash, so the config edit and hash append cannot be split across tasks.

### Task 1: Copper Sword → console dispatch

**Files:**
- Modify: `src/main/resources/config.yml` (Copper Sword button, lines 105-109)
- Modify: `src/main/resources/config-hashes.txt` (append new hash)
- Modify: `src/test/java/org/xpfarm/pizza/config/ShippedConfigTest.java:51`
- Modify: `pom.xml` (version `0.5.0` → `0.5.1`)

**Interfaces:**
- Consumes: existing `ConfigParser.parse`, `Action.RunCommand.command()` (unchanged).
- Produces: the shipped Copper Sword button dispatches `copperkingdom give copper_sword %player%` as console with no grant.

- [ ] **Step 1: Update the failing test assertion**

In `src/test/java/org/xpfarm/pizza/config/ShippedConfigTest.java`, change line 51 from:

```java
        assertTrue(commands.contains("copperkingdom give copper_sword"));
```

to:

```java
        assertTrue(commands.contains("copperkingdom give copper_sword %player%"));
```

- [ ] **Step 2: Run to verify it fails**

- [ ] **Step 3: Switch the Copper Sword button to console**

In `src/main/resources/config.yml`, replace the Copper Sword button (currently lines 105-109):

```yaml
      - label: Copper Sword
        image: { material: COPPER_INGOT }
```

with:

```yaml
      - label: Copper Sword
        image: { material: COPPER_INGOT }
        run-as: console
```

(Drop the `grant:` line, change `run-as` to `console`, append `%player%` to the command. Keep the `image:` line.)
