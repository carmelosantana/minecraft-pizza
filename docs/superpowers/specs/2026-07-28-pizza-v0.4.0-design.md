# Pizza v0.4.0 — Timber Blast + Gluten-Free Bread catalog adds

Date: 2026-07-28
Status: approved
Branch: `feat/pizza-v0.4.0`

## Summary

Add two items to the **Cool Items** (`catalog`) menu — a **Timber Blast Axe** and a
**Sweet (gluten-free) Bread** — reusing the exact console-give pattern established by the v0.2.0
catalog additions (Agua de Florida, Electric Furnace, Llama). No Java changes, no new permissions,
no new button shapes. This is a data + test + version change only.

The curse mechanics were reviewed this cycle and found sound (see Non-goals); nothing about the
curse changes here.

## Motivation

The two source plugins already ship on the stack and expose clean give commands. Surfacing them in
Pizza lets younger players grab them from the touch menu the same way they grab the existing
catalog items. Timber Blast (a one-swing tree-feller) and a health-buff bread are both age-appropriate
and self-contained.

## Design

### 1. Timber Blast Axe → `catalog`

```yaml
- label: Timber Blast Axe
  run-as: console
  command: timberblast give %player%
  cooldown: 24h
```

- `/timberblast give <player>` is `timberblast.admin` (default op); the console sender holds op, so
  console dispatch works — identical to Electric Furnace / Llama.
- 24h cooldown: it is a keepable tool (burns one gunpowder per fell), not a consumable, so a
  once-a-day grab is the right cadence.

### 2. Sweet Bread → `catalog`

```yaml
- label: Sweet Bread
  run-as: console
  command: gfbread give sweet %player% 3
  cooldown: 15m
```

- GlutenFreeBread's four-arg form `gfbread give <type> <player> <amount>` resolves the *target* and
  only requires the *target* to be a player — the sender may be console. Verified in
  `GFBreadCommand.giveBreadToPlayer` (checks `target instanceof Player`, never the sender).
- Type `sweet` chosen as the friendliest of `plain|sweet|spicy|savory`; amount `3` is a snack.
  Both are a trivial config swap later.
- 15m cooldown (per product decision) so bread is a frequent snack, not a stockpile. This is Pizza's
  own throttle, independent of GlutenFreeBread's internal 5-per-5-minutes consume limit.

### 3. Allowlist

Add two roots so the new commands pass the fail-closed `command-allowlist` re-check. The allowlist
matches a command's **first token** (`CommandAllowlist.rootOf`), so the bread root is `gfbread` — the
command name — not the plugin's artifact name `glutenfreebread`:

```yaml
- timberblast
- gfbread
```

### 4. Config self-refresh obligation

Editing `config.yml` changes its SHA-256. Per the v0.3.0 mechanism:

- Append the **new** default's sha256 as the last (current) line of `src/main/resources/config-hashes.txt`.
- Keep the three existing hashes as known-older defaults so an unmodified v0.3.0 config **auto-heals**
  to the v0.4.0 default on upgrade — the two new items simply appear, no manual edit, old file backed up.
- `ConfigHashesTest.currentDefaultHashIsListed` fails CI if the new hash is not appended.

### 5. Version

`pom.xml` `0.3.0` → `0.4.0`.

## Testing

Extend `ShippedConfigTest` (same pattern as the existing v0.2.0 assertions):

- `newCatalogButtonsAreAcceptedAndDispatchTheirCommands` — also assert the catalog contains
  `timberblast give %player%` and `gfbread give sweet %player% 3`.
- `newRootsAreInTheAllowlist` — also assert `timberblast` and `gfbread`.
- `shippedConfigParsesWithoutWarnings` must stay green (roots present ⇒ no "not allowlisted" warning).

Full `mvn -q verify` must pass (current suite 104 tests → grows by the extended assertions, count
unchanged since assertions are added to existing tests). `ConfigHashesTest.currentDefaultHashIsListed`
guards the hash update.

## Non-goals

- **Curse changes.** Reviewed and sound: `curse trigger ZP25 %target%` and `curse stop %target%`
  both require `curse.admin` (console holds it), console must pass an explicit target (Pizza supplies
  `%target%`), `ZP25` is a valid mechanic id, and `stop` fully cleanses (stops plague + ends all
  mechanics). Two noted runtime caveats for the play-test, not code changes: (a) `trigger` no-ops if
  `ZP25` is disabled in TheCurse's own config; (b) the victim sees "An admin has triggered…" wording
  that lives in TheCurse.
- **Copper Kingdom, GeoBrot fractal-world travel, Farmers Market shop.** Each adds a new button shape
  or menu surface (Copper Kingdom's `give` is self-only → needs a `player-elevated` button; fractal
  travel is a Travel-menu add; Market opens a GUI). Parked for a later cycle.
